OmniBrain: Multi-Modal Agentic Architecture & Model Map

End-to-End Orchestration & Sub-Agent Technical Responsibilities

info System Overview

OmniBrain is an Agentic Multi-Modal Intelligence platform designed to analyze complex corporate financial filings like 10-K annual reports.

Built over two phases, the system first establishes a multi-modal ingestion pipeline using PyMuPDF to parse text and isolate financial charts, indexing them in a Qdrant Vector Database and serving them via an asynchronous FastAPI backend. The core intelligence relies on a stateful, cyclic LangGraph workflow orchestrated by a Supervisor Node for dynamic task routing and loop safety. This Supervisor coordinates targeted sub-agents: a SearchAgent for vector retrieval, Self-RAG for context grading, a SQLAgent for quantitative queries, and a VisionAgent for interpreting financial charts. All of this feeds into an interactive UI that displays real-time agent thought processes, chart citations, and comprehensive investment memos.

Which Model & Engine Handles What

Supervisor Orchestrator LangGraph

Stateful cyclic state machine operating on shared AgentState. Evaluates analyst query intent, manages iteration counters (hard ceiling of 4 cycles), and dynamically delegates tasks to specialized sub-agents.

Engine: LangGraph Cyclic StateGraph • MemorySaver
VisionAgent & Analytics Gemini / GPT-4o

VLM prompt engineering with strict Pydantic JSON schema extraction. Deterministic Python visual analytics computes exact CAGR, YoY period-over-period growth, and outlier detection with zero LLM math hallucination.

Engine: gemini-flash-lite-latest • GPT-4o • PIL Preprocessor
SearchAgent & Self-RAG Qdrant Vector DB

Dense vector retrieval over 500-token chunks with 100-token overlap. Features an iterative Self-RAG relevance loop that grades retrieved text and autonomously rewrites queries if context is insufficient.

Engine: Qdrant DB • Dense Embeddings • Self-RAG Grader
SQLAgent (Text-to-SQL) SQLite / Gemini

Translates equity valuation queries into SQL to retrieve structured market metrics (stock prices, P/E ratios, market capitalization, 52-week ranges) with deterministic fallback rules.

Engine: Text-to-SQL Generator • SQLite financial_data.db
Multi-Modal Ingestion PyMuPDF + FastAPI

High-fidelity PDF parsing extracting hierarchical text and embedded vector drawing figures (>100x100px), serving assets asynchronously through FastAPI endpoints (/api/v1/ingest, /api/v1/images).

Engine: PyMuPDF (fitz) • Semantic Chunker • FastAPI Uvicorn
Safety & Telemetry Guardrails & Traces

Deterministic input guardrails prevent prompt injection and off-topic queries. Cross-modal verifier checks visual numbers against text context to prevent hallucinations, while Langfuse tracks latencies and tokens.

Engine: NeMo-style Guardrails • Langfuse Tracing Manager
